# RASAD (رصد)

برنامه‌ی ویندوزی برای محاسبه‌ی **میانگین درصد قیمت آخرین معامله‌ی شرکت‌های منتخب** بورس و فرابورس ایران.

- هر ۲ دقیقه فایل اکسل `MarketWatchPlus` را از tsetmc دانلود می‌کند.
- نام شرکت‌های فهرست (`assets/namad.txt`) را با ستون «نام» فایل تطبیق می‌دهد (بدون تفاوت ی/ي و ک/ك و فاصله‌ها).
- میانگین «درصد آخرین معامله» را حساب و نمودار روند می‌کشد. نماد دلخواه را هم می‌توان روی نمودار اضافه کرد.
- تب «شرکت‌های منتخب» نشان می‌دهد هر شرکت با کدام نماد تطبیق خورده (دقیق / تقریبی / یافت نشد).
- ردیف‌های بلوکی و تال (نماد پایان‌یافته با ۲ یا ۳)، اختیار و صندوق درآمد ثابت هیچ‌وقت انتخاب نمی‌شوند؛
  اگر چند نماد هم‌نام بودند، نمادی که تعداد معامله‌ی بیشتری دارد انتخاب می‌شود.

## ویرایش فهرست شرکت‌ها
دکمه‌ی «ویرایش فهرست شرکت‌ها» فایل `%APPDATA%\RASAD\namad.txt` را باز می‌کند (هر خط یک نام شرکت).
بعد از ذخیره، در به‌روزرسانی بعدی اعمال می‌شود.

## ساخت installer روی GitHub
```
git tag v2.0.0
git push origin v2.0.0
```
فایل `RASAD-Setup-2.0.0.exe` در بخش Releases ساخته می‌شود.

## اجرا از سورس
```
pip install -r requirements.txt
python app/rasad.py
```
